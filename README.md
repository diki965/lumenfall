LUMENFALL — an arena beacon-defense shooter: pilot a ship guarding a central beacon against 10 waves of enemies. Chasers swarm, shooters fire back, tanks soak damage, and a boss guards the later waves; clearing wave 10 wins. Between waves, spend the shards enemies drop on upgrades (fire rate, damage, multishot, pierce, speed, repairs). Pure static files — vanilla JavaScript + canvas 2D + WebAudio synth sound, no libraries and no network requests. Entry for the [make.fun bounty](https://make.fun/bounty/best-game-01) "Make the best game".

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## How to play

- **WASD / arrow keys** — move the ship
- **Mouse** — aim
- **Hold click or Space** — fire
- **P** — pause, **M** — mute

Defend the beacon in the middle of the arena: if it falls, the run ends. Kills drop shards — collect them and choose an upgrade when a wave clears. Score 10,345 with 234 kills wins the run in about 9 minutes; the game tracks your best score locally.
